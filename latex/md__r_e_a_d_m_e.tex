This is a full-\/stack messenger application built with C++ backend microservices and a Qt frontend. It supports real-\/time messaging, asynchronous request handling, and high-\/throughput performance. The backend uses Crow framework, Rabbit\+MQ, Redis, and a custom SQLite ORM.
